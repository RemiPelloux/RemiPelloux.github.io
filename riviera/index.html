Chapter 01, where I come from

Born on the Cap

I was born in Antibes, on the cape between Nice and Cannes. I studied a few kilometres inland at Sophia Antipolis, and I now build software in Nice.

What I build

Products, and tools in my own time

I am CTO and co-founder of OpenPro, a French professional network with AI matching. In my own time I build an IDE that runs on your own models, a local vault for voice recordings and a container runtime in Rust.

How I think

Software you can keep

I like software that runs on your machine, keeps your data there and can be read by the next person. My rules for AI coding agents fit on one page: files under 400 lines, functions under 25.

The other side

I take software apart too

In 2026 I reported an XSS in Symfony, now CVE-2026-45753, and I study the firmware of devices I own.

    Chapter 04, flagships

    OpenVision

    An IDE that runs on your machine with the models you choose. It has an editor, terminals, Git worktrees, an agent and Tab completion, and connects to any OpenAI-compatible API or to a local model. It needs no account and sends no telemetry.

    2026, preview 0.2Electron, TypeScript, MCP

    GitHub

    OpenPlod

    A vault on your own disk for Plaud Note Pro recordings. It imports audio over Bluetooth, keeps the original files and turns them into transcripts, Markdown documents and chats that cite their sources. It ships with a REST API and a read-only MCP server.

    2026, MITTauri, Rust, TypeScript

    GitHub Case study

    Modelly

    A framework for agent-based modeling in Python. Scenarios are typed and every run is seeded, so a shared config returns the same numbers. Agents are numpy-backed, on grids, networks and continuous space, with pandas data collection.

    2026, Apache-2.0Python, numpy, pandas

    Documentation Case study

    Containust

    A container runtime in Rust with no background daemon. Each ctst command talks to the backend directly. Stacks are described in a small declarative language, images are pulled by pinned digest, and an offline flag blocks the network for air-gapped machines.

    2026, source-availableRust

    GitHub Case study

    HackoogleMini

    I am reverse engineering the Google Home Mini to replace Google Assistant with a local LLM and an MCP voice bot. The repository covers YAFFS2 kernel exploit research, the BLE setup protocol and firmware acquisition.

    2026, security researchPython

    GitHub

    Pelloux Guidelines

    Ten rules that keep code written by AI agents small enough to review, with hard limits: 400 lines a file, 25 a function, three parameters. An audit with no dependencies checks them in the agent loop, before each commit and in CI. They run in more than thirty repositories, this site included.

    2026, MITPython, Markdown

    GitHub

    SmarttyTest

    SmarttyTest runs only the tests a change can affect, across Jest, Vitest, node:test, Playwright, Cypress and Angular. Every skipped test comes with a reason.

    2026, Apache-2.0TypeScript

    Site GitHub

    OpenSw

    An open-source Nintendo Switch emulator for Android ARM64 phones and handhelds, with Vulkan rendering and a profile for each game.

    2026, GPLv3C++, Vulkan

    GitHub

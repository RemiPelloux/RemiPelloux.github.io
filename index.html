02A seeded run

Reproducible runs are the point of Modelly. Here is the idea in 100 lines of JavaScript: a Schelling model where each agent moves when fewer than 45 % of its neighbours match it.

The model needs JavaScript.

Run it twice with the same seed and the readout ends on the same numbers. Change the seed and the clusters land elsewhere.

03At OpenPro

OpenPro is a French professional network for people, jobs and companies, with video CVs, AI matching, messaging and an assistant named Mia, on web, iOS and Android.

The code is private. As CTO since February 2023, this is the engineering I answer for.

  • Product platform. A PHP and Symfony core, TypeScript and React on the web, apps for iOS and Android, shipped on one roadmap.
  • Applied AI. Matching, retrieval and the Mia assistant, written in Python and connected through MCP.
  • Open integrations. ATS connectors through a public SDK over HTTP and MCP.
  • Infrastructure. PostgreSQL and Redis on AWS, in Docker, released through CI/CD, hosted in the EU under GDPR.

Other products I built and run: LeadsIt, B2B lead lists from Google Maps, OpenWhistle, audio turned into structured data, and deal-club.fun, a French real-estate card game that plays offline.

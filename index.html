01Selected work

  1. 01

    OpenVision

    An AI coding workspace where you choose the models. It puts an explorer, an editor, terminals, Git worktrees, agents and Tab autocomplete in one desktop app, pointed at any OpenAI-compatible API or a server on 127.0.0.1. You do not need an account to use it.

    2026, development preview
    Portable Windows x64 build
    Electron, TypeScript, MCP
  2. 02

    OpenPlod

    A vault on your own disk for Plaud Note Pro recordings. It imports audio over Bluetooth, keeps the original files and turns them into transcripts, Markdown documents and chats that cite their sources. It ships with a REST API and a read-only MCP server.

    Read the case study

    2026, MIT
    39 stars on GitHub
    Tauri, Rust, TypeScript
  3. 03

    Modelly

    A framework for agent-based modeling in Python. Scenarios are typed and every run is seeded, so a shared config returns the same numbers. Agents are numpy-backed, on grids, networks and continuous space, with pandas data collection.

    Read the case study

    2026, Apache-2.0
    Docs published on GitHub Pages
    Python, numpy, pandas, C
  4. 04

    HackoogleMini

    I am reverse engineering the Google Home Mini to replace Google Assistant with a local LLM and an MCP voice bot. The repository covers YAFFS2 kernel exploit research, the BLE setup protocol and firmware acquisition.

    2026, security research
    21 stars on GitHub
    Python
  5. 05

    Containust

    A container runtime in Rust with no background daemon. Each ctst command talks to the backend directly. Stacks are described in a small declarative language, images are pulled by pinned digest, and an offline flag blocks the network for air-gapped machines.

    Read the case study

    2026, source-available
    Linux namespaces, cgroups v2, OCI
    Rust
  6. 06

    unslop

    Rules for interfaces and copy that do not look machine-made, with scripts that check them: no shadows, no gradients, no emoji, 350 banned words. The colours, type and copy of this site follow them.

    2026
    Skill, linter and scanner
    Python, Markdown
  7. 07

    SmarttyTest

    SmarttyTest runs only the tests a change can affect, across Jest, Vitest, node:test, Playwright, Cypress and Angular. Every skipped test comes with a reason.

    2026, Apache-2.0
    Python and PHP in preview
    TypeScript

03At OpenPro

OpenPro is a French professional network for people, jobs and companies, with video CVs, AI matching, messaging and an assistant named Mia, on web, iOS and Android.

The code is private. I have been CTO since February 2023, and this is the engineering I answer for.

  • A PHP and Symfony core, TypeScript and React on the web, apps for iOS and Android, shipped on one roadmap.
  • Matching, retrieval and the Mia assistant, written in Python and connected through MCP.
  • ATS connectors through a public SDK over HTTP and MCP.
  • PostgreSQL and Redis on AWS, in Docker, released through CI/CD, hosted in the EU under GDPR.

Other products I built and run: LeadsIt, an automated B2B lead search platform, OpenWhistle, audio turned into structured data, and deal-club.fun, a French real-estate card game that plays offline.
